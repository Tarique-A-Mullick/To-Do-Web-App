## 📌 About The Project

**TaskFlow** is a modern task-management web application designed to
provide a simple and distraction-free way to organise everyday tasks.

Users can create tasks, edit them, mark them as completed, delete them,
and optionally assign a **date and time reminder** to individual tasks.

Unlike a traditional to-do list, TaskFlow combines task management with
a lightweight reminder system while keeping the interface clean,
responsive and easy to use.

The application runs entirely in the browser and uses **LocalStorage**
to preserve task data between sessions.

---

## ✨ Why TaskFlow?

Task management should be simple.

TaskFlow focuses on three principles:

| Principle | Goal |
|---|---|
| 🎯 **Simple** | Create and manage tasks without unnecessary complexity |
| ⏰ **Flexible** | Add reminders only when a task actually needs one |
| 🎨 **Clean** | Provide a polished and distraction-free interface |

# 🚀 Features

## 📝 Task Management

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- ↩️ Move completed tasks back to pending
- 🗑️ Delete individual tasks
- 🧹 Clear all completed tasks
- 🔢 Pending task counter
- 🔢 Completed task counter

---

## ⏰ Smart Reminder System

Reminders are **completely optional**.

Users can create a normal task without setting a reminder, or assign a
specific date and time when the task needs attention.

### Reminder Features

- 🔔 Add an optional reminder
- 📅 Select date and time
- ⏰ Display reminder information on the task
- ✏️ Edit an existing reminder
- ❌ Remove an existing reminder
- 🔊 Play an alarm when the reminder triggers
- 🖥️ Browser notification support
- 💾 Save reminder information using LocalStorage
- ⚠️ Prevent reminders from being set in the past
