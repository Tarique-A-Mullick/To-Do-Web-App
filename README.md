# ◈ ABOUT TASKFLOW

**TaskFlow** is a modern browser-based task management application
designed to make everyday productivity simple, organised and visually
engaging.

The application allows users to:

- Create new tasks
- Edit existing tasks
- Complete tasks
- Delete tasks
- Track pending and completed tasks
- Set optional reminders
- Edit existing reminders
- Remove reminders
- Receive reminder notifications
- Store tasks locally in the browser

The application requires **no backend server or database** for its
current functionality.

---

# ◈ THE IDEA

TaskFlow was built around a simple principle:

> **Productivity tools should help you focus, not distract you.**

Instead of making every task complicated, TaskFlow keeps the basic task
management experience simple while allowing users to add additional
functionality such as reminders whenever they need it.

The result is a lightweight productivity application combining:

# ◈ CORE FEATURES

## 📝 Task Management

| Feature | Description |
|:---|:---|
| ➕ Add Task | Create a new task quickly |
| ✏️ Edit Task | Modify an existing task |
| ✅ Complete Task | Mark a task as completed |
| 🗑️ Delete Task | Remove an individual task |
| 🧹 Clear Completed | Remove all completed tasks |

---

## ⏰ Reminder System

The reminder system is designed to be **completely optional**.

Users can create a task without setting a reminder, or assign a specific
date and time when a reminder is useful.

| Feature | Description |
|:---|:---|
| 🔔 Add Reminder | Attach a reminder to a task |
| 📅 Date & Time | Choose when the reminder should trigger |
| ✏️ Edit Reminder | Change an existing reminder |
| ❌ Remove Reminder | Remove a reminder from a task |
| 🔊 Alarm | Play an alarm when triggered |
| 🖥️ Notification | Display a browser notification |
